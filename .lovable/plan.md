

# ProConvert – Smart Unit Converter

## 1. Create conversion data and logic module
- Define all unit categories with their units and conversion factors
- Implement ratio-based conversion for Length, Mass, Time, Speed, Area, Volume
- Implement formula-based conversion for Temperature (°C, °F, K)
- Precision to 4 decimal places

## 2. Build the main ProConvert page
- Animated gradient background (slow color shift via CSS keyframes)
- Centered glassmorphism card (backdrop-blur, semi-transparent bg, rounded-2xl, soft shadow)
- Dark/light theme toggle button in top corner with smooth transition
- Footer: "Built with ❤️ using HTML, CSS & JavaScript"

## 3. Build the converter UI components
- Category dropdown selector (Length, Mass, Temperature, Time, Speed, Area, Volume)
- Dynamic "From" and "To" unit dropdowns that update when category changes
- Numeric input field with glow focus effect
- Swap button between From/To with rotation animation
- Convert button (also real-time conversion on typing)
- Animated result display (fade-in / slide-up)

## 4. Add validation and error handling

- Show animated error message below input
